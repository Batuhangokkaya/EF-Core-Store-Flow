# 🚀 Entity Framework Core Masterclass (70+ LINQ & EF Core Metodu)

Bu repository, Murat Yücedağ hocamın Entity Framework Core Masterclass** eğitimi kapsamında öğrendiğim **70+ LINQ** ve **Entity Framework Core** metodunun örneklerini içermektedir.
Bu proje sayesinde farklı sorgu senaryolarını uygulayarak LINQ ve Entity Framework Core'un çalışma mantığını öğrenmeyi ve günlük projelerde doğru kullanımını pekiştirmeyi amaçladım.
